# BimBam-Buy-Agent
BimBam Agent es el encargado de brindar informacion en cuanto a las politicas de rembolso, devoluciones, programa de Afiliados, guia de tiempos y constos de envio, preguntas frecuentessobre metodos de pago y manual de garantis de productos del E-commerce multiplataforma BimBam Buy.


##Determinacion del Alcance:
De acuerdo a los documentos que fueron cargados; BimBamBuy-Agent cuenta con 5 enfoques diferentes y se agregaron preguntas clave que el agente debe ser capaz de responder con exito rn cada enfoque.

1- Logística y Envíos (guia_de_tiempos_y_costos_de_envio_bimbam_buy.pdf)
¿Cuánto cuesta el envío a una zona extendida o cómo sé si aplica envío gratis?
¿Qué pasa si mi paquete no llega o si la entrega resulta fallida?
¿Cuáles son las ventanas de entrega estándar para LATAM?

2- Garantías y Servicio Técnico (manual_de_garantia_de_productos_de_bimbam_buy.pdf)
¿Qué cubre y qué excluye la garantía de BimBam Buy?
¿Qué evidencias (fotos, videos, seriales) le tengo que pedir al cliente si reclama una falla?
¿Se puede aprobar una garantía si el producto fue reparado por un tercero?

3- Finanzas y Pagos (metodos_de_pago_preguntas_frecuentes_bimbam_buy.pdf)
¿Qué medios de pago están disponibles y cuánto tarda en conciliarse un pago duplicado?
¿Se puede confirmar una orden solo con una captura de pantalla enviada por el cliente?
¿Qué hacer ante un rechazo recurrente en el checkout?

4- Reembolsos y Devoluciones (reembolsos_devoluciones_politica_bimbam_buy.pdf)
¿Cuáles son los plazos y condiciones indispensables para aceptar una devolución?
¿Se puede procesar un reembolso o cambio sin que el cliente retorne físicamente el producto?
¿Cuándo se debe escalar un caso al área superior por temas reputacionales?

5- Comercial y Afiliados (programa_de_afiliados_bimbam_buy.pdf)
¿Cómo funciona la atribución de ventas y el pago de comisiones para los creadores de contenido?
¿Qué materiales están permitidos y cuáles penalizan o suspenden la cuenta del afiliado?
