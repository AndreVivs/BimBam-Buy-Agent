# BimBam-Buy-Agent
BimBam Agent es el encargado de brindar informacion en cuanto a las politicas de rembolso, devoluciones, programa de Afiliados, guia de tiempos y constos de envio, preguntas frecuentessobre metodos de pago y manual de garantis de productos del E-commerce multiplataforma BimBam Buy.
